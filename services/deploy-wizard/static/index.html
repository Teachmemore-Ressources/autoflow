Root CA + Wildcard Certificate (via PKI service)
Starts the PKI service, creates the Autoflow Root CA, then issues a wildcard certificate for your domain.
Writes traefik/certs/wildcard.<domain>.crt/.key and updates traefik/dynamic/tls.yml.
⚠ Requires PKI_ADMIN_PASSWORD to be set in the PKI section before running.
